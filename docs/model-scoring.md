# Model Scoring

Goal: define scored fields and philosphy behind each.

## Path scores

```
Version: 0.1
Last updated: 2026-10-11
```

`Path scores` provide path quality scores, with high scores indicating a more pleasant trip segment by balancing safety and other factors. See [data-model.md](data-model.md) for details and components.

Initial model should include weighted components of speed limit, path type (road, multiuse, etc.), and bike accomodations.

Future iterations can incorporate other derived scores, including traffic, intersection quality, scenery, etc.
